# Standard Operating Procedure: Control Valve Overhaul & Seat Leakage Testing (SOP-VLV-202)

## 1. Purpose
Defines inspection, gland packing maintenance, actuator calibration, and seat leakage testing for process control valves and emergency shutdown valves (SDVs) per ANSI/FCI 70-2 and API 598.

## 2. Pre-Maintenance Isolation
- Apply Double Block and Bleed (DBB) isolation on upstream and downstream headers.
- Depressurize bonnet bleed port; verify zero gauge pressure.
- Disconnect instrument air supply line (lock vent port open); disconnect 4-20 mA HART signal.

## 3. Inspection & Leakage Classification (ANSI/FCI 70-2)
- Class IV: Metal-to-metal seating. Maximum allowable leakage 0.01% of rated valve capacity.
- Class V: Critical process service. Maximum leakage 0.0005 ml/min per psi per inch orifice.
- Class VI: Resilient soft seat (PTFE/PEEK). Zero visible bubbles during 1-minute pneumatic test at 50 psi.

## 4. Packing Gland & Stem Inspection
- Inspect valve stem for pitting, scoring, and runout (maximum allowable stem runout: 0.02 mm).
- Replace PTFE/graphite chevron packing rings during every turnaround.
- Torque gland flange bolts uniformly to specified torque (35 Nm for 1-inch stem) using calibrated torque wrench.

## 5. Hydrostatic Proof & Functional Stroke Test
- High-pressure water shell test at 1.5x valve body rating for 3 minutes.
- Pneumatic seat test per API 598 at 1.1x design differential pressure.
- Calibrate digital valve positioner across 0%, 25%, 50%, 75%, 100% stroke with hysteretic deviation < 0.5%.
