# Standard ISA-5.1 & ASME B31.3: Instrumentation and Piping Identification

## 1. Scope & Application
This standard document provides sovereign reference specifications for process piping and instrumentation diagram (P&ID) symbology per ANSI/ISA-5.1-2009 and ASME B31.3 Process Piping specifications.

## 2. ISA-5.1 Instrument Identification Letters
The first letter identifies the measured or initiating variable:
- **P**: Pressure / Vacuum (e.g. PT = Pressure Transmitter, PI = Pressure Indicator, PSV = Pressure Safety Valve)
- **T**: Temperature (e.g. TT = Temperature Transmitter, TI = Temperature Indicator, TE = Temperature Element)
- **F**: Flow Rate (e.g. FT = Flow Transmitter, FI = Flow Indicator, FO = Flow Orifice)
- **L**: Level (e.g. LT = Level Transmitter, LI = Level Indicator, LG = Level Gauge)

Subsequent letters specify readout or output functions:
- **I**: Indicator (direct readout instrument)
- **T**: Transmitter (converts sensor reading to electrical/pneumatic signal)
- **V**: Valve (final control element or manual block valve)
- **A**: Alarm (annunciation)
- **C**: Controller (automatic process loop controller)

Example: **PT-1027** designates a Pressure Transmitter in process loop 1027. **PI-1027** designates a Pressure Indicator in the same pressure monitoring loop. **V-1063** designates an inline process isolation valve.

## 3. ASME B31.3 Piping Line Types
- **Continuous Solid Line**: Primary process line conveying operating fluids under design pressure.
- **Dashed Line (----)**: Instrument electric or pneumatic signal loop connecting field transmitters to control systems.
- **Double Solid Line**: High pressure containment piping or jacketed lines.

## 4. Equipment Symbology
- **Pumps**: Circular casing with tangential discharge nozzle. Tag prefix 'P-' (e.g. P-101).
- **Vessels**: Elongated cylindrical enclosures with dished heads. Tag prefix 'V-' or 'TK-'.
- **Valves**: Opposed triangles representing gate, globe, or check valve bodies.
